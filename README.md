# cpp-arrays-functions
# C++ Programs: Arrays and Functions

This repository contains C++ programs that demonstrate the use of **arrays** and **functions**, essential concepts in programming logic and modular code design.

---

## 📂 Programs Included

### ARRAY PROGRAMS
1. **sum_of_array.cpp**  
   Takes user input and calculates the sum of all array elements.

2. **max_min_array.cpp**  
   Finds the maximum and minimum values inside an array.

3. **reverse_array.cpp**  
   Reverses the elements of an array.

---

### FUNCTION PROGRAMS
4. **factorial_function.cpp**  
   Uses a user-defined function to calculate factorial.

5. **prime_check_function.cpp**  
   A function that checks whether a number is prime or not.

---
